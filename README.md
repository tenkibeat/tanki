# tanki — 短期予報解説を日英で読む

気象庁「短期予報解説資料」を、英訳・単語・音声つきで毎日自動公開します。

- 公開ページ: https://tenkibeat.github.io/tanki/ （最新号）／ archive.html（バックナンバー）
- 毎時17分に新しい号をチェック → Gemini APIで英訳・単語 → Kokoroで音声 → GitHub Pagesに公開
- 本文・英訳・単語は `data/` にずっと保存。音声は公開から1か月で自動削除
- 公開用の `gh-pages` ブランチは毎回作り直し（履歴を持たない）

必要な設定: リポジトリの Secrets に `GEMINI_API_KEY`。

原文の出典: 気象庁ホームページ。英訳・単語は生成AIによるもので、誤りを含むことがあります。
